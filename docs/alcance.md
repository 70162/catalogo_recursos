La idea de este proyecto es hacer un catálogo que ayude a los estudiantes a guardar y encontrar recursos para sus actividades escolares.

Más adelante, el sistema podría tener funciones como:

1. Agregar nuevos recursos.
2. Buscar recursos por nombre o tema.
3. Ordenar los recursos por tipo.
4. Ver la información de cada recurso.
5. Cambiar o eliminar un recurso.
6. Buscar recursos por autor o por la página de donde se obtuvieron.

Por ahora, solamente se va a preparar la estructura del proyecto y agregar algunos ejemplos. Las demás funciones se podrían hacer después.
